Mail Check

Checks Wellfound, Hubstaff, Sulekha, CazVid, GoHire, Indeed, LinkedIn, and forwarded job-site mail. Keeps American, Canada, EU, and Latin America. The Job site cell records the platform.

Fast by default: messages already checked are remembered, so each run only opens new mail. Tags: confirmed US = red, Canada/EU/Latina = yellow, weak location = a third tag in Thunderbird, plus a star. The same mail is copied into Mail Check folders (American, Canada, European, Latina, Possible) so Outlook and other apps can open them. Wellfound and other job-site applications (Hubstaff, Sulekha, CazVid, GoHire, Indeed, LinkedIn, and forwarded board mail) use the same location check: profile city and university only. Those candidates land on the American, European, and Latina sheets. The Job site cell names the platform; Wellfound is gold. Asian and African candidates from those platforms are rejected. Possible means the profile city is only a continent or is missing, and the university does not confirm it. If Thunderbird still shows old unread/no tags: right-click Inbox → Properties → Repair Folder, then turn on the Tags column (column picker).
